# RudWEb 2007-2009

My first PHP site engine, from the site code of The Underground Beat (2007) through ubws and rsweb to RudWEb 0.8
(2008), and the MVC rewrite that followed. A historical archive, kept read-only: PHP 4 and 5 code with `mysql_*` calls,
not safe to deploy.

## Its place in the line

RudWEb → WEb is my PHP framework line, one archive per era:

1. **rudweb-2007-2009** (this one): the first engine and RudWEb 0.1 to 0.8;
2. [rudweb-2009-2011](https://github.com/webservco-legacy/rudweb-2009-2011): RudWEb 1 to 4 in Subversion, then 5.0, the
   rewrite from scratch; [rudwi](https://github.com/webservco-legacy/rudwi), the web desktop, and
   [rudweb-extras](https://github.com/webservco-legacy/rudweb-extras), the tutorials, skins and logos, belong to it;
3. [web-2012-2017](https://github.com/webservco-legacy/web-2012-2017): WEb 5 to 7;
4. [web7](https://github.com/webservco-legacy/web7): WEb7 as a git archive;
5. the framework in git since 2017: [framework, branch v9](https://github.com/webservco/framework/tree/v9), then
   [framework](https://github.com/webservco/framework) (v10 to v13) and the WebServCo components.

## What is in it

- `main`: the engine in `kit/` (shop, catalogue, tags, comments, contact and sign-up modules, captchas, SEO URLs, English,
  Romanian and Italian), the setup utility in `setup/`, my skins and themes, the work folder of each snapshot (tests,
  snippets, the generated phpDocumentor pages) and the side material in `extra/`;
- `site-2007-09`: the site code of The Underground Beat, 2007-09 to 2007-10;
- `mvc-2008-12`: the MVC rewrite and my tests on it, 2008-12 to 2009-02.

Left out of the whole history: the sites and themes I built on the engine for clients and for an employer, their
configs and databases, other people's data (a product table, a vehicle catalogue, a box set's track list), copies of
free-hosting accounts, and downloaded templates, fonts and packages whose licences I cannot name. Where a client's name
was left in code or in a comment, it reads `travel-agency` (`travel_agency` inside a longer name); passwords read `REDACTED`.

## How it was built

From the dated tar snapshots I kept of the engine and its work folder, and the copies of the site and of the MVC
rewrite, turned into commits in 2026 (48 on `main`), with the dates of the snapshots kept. Archives that held
credentials were expanded in place and redacted. The last commits before this README set LF line endings and indent
with spaces.

## Third-party code

Bundled as it shipped: FCKeditor 2.x in `kit/lib/editor/` and its archives (GPL, LGPL or MPL), Prototype and
script.aculo.us in `kit/inc/js/` (MIT), Smarty in the MVC rewrite (LGPL), the Bitstream Vera Mono font (Bitstream Vera
licence), the Dustismo and 01 Digit fonts and a world flag icon set, each with its own licence text where the package had
one. The pages in `work/tmp/docs/` were generated by phpDocumentor from my code.
